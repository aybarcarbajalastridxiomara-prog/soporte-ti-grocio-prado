
# Backend - Sistema de Soporte TI

Este directorio contendrá la lógica de negocio del sistema de gestión y seguimiento de incidencias de la Municipalidad Distrital de Grocio Prado.

## Funcionalidades previstas

- Autenticación y autorización de usuarios.
- Registro y gestión de incidencias.
- Clasificación y asignación de tickets.
- Registro de intervenciones técnicas.
- Seguimiento y cierre de incidencias.
- Consulta del historial y reportes.

**Tecnología propuesta:** Python.

**Estado:** En preparación.
