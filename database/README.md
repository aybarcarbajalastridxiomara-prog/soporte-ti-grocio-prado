
# Base de Datos - Sistema de Soporte TI

Este directorio contendrá el diseño y los scripts SQL de la base de datos del sistema de gestión y seguimiento de incidencias de la Municipalidad Distrital de Grocio Prado.

## Contenido previsto

- Diagrama entidad-relación.
- Diccionario de datos.
- Script SQL para crear las tablas.
- Relaciones y restricciones de integridad.
- Scripts de datos de prueba.
- Consultas SQL para verificar el funcionamiento.

## Tecnología propuesta

- PostgreSQL.
- Supabase como servicio de base de datos.

## Entidades principales previstas

- Áreas municipales.
- Usuarios y roles.
- Incidencias.
- Equipos.
- Asignaciones.
- Intervenciones técnicas.
- Evidencias.
- Historial de incidencias.
- Dependencias.
- Conformidades.
- Informes técnicos.

**Estado:** Diseño en preparación.
