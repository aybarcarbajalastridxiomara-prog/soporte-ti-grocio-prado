
# Documentación - Sistema de Soporte TI

Este directorio contendrá la documentación del proyecto de gestión y seguimiento de incidencias de la Municipalidad Distrital de Grocio Prado.

## Documentación prevista

- Levantamiento de información y análisis de entrevistas.
- Diagnóstico del proceso actual (AS-IS).
- Propuesta del proceso mejorado (TO-BE).
- Requerimientos funcionales y no funcionales.
- Arquitectura del software.
- Diagramas UML.
- Planificación de actividades con Scrum.
- Product Backlog y Sprint Backlog.
- Diagramas de Gantt.
- Prototipos desarrollados en Figma.
- Casos de prueba y resultados.
- Informe final del proyecto.

## Metodología

Scrum, mediante el desarrollo iterativo e incremental.

## Estado

Documentación en elaboración y actualización progresiva.
